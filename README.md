# Edge Detection using Sobel, Prewitt and Canny

This project performs edge detection on a grayscale image using three techniques:

* Sobel Edge Detection
* Prewitt Edge Detection
* Canny Edge Detection

## Requirements

* Python
* OpenCV
* NumPy
* Matplotlib

## Input

`nature.JPG`

## Output

The program compares the original grayscale image with the Sobel, Prewitt, and Canny edge detection results.

Output file:

`output/edge_detection_comparison.png`
